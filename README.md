# 50 Ejercicios de Programación en Python y Java

Este repositorio contiene la solución a 50 ejercicios básicos de programación, 
resueltos en dos lenguajes: **Python** y **Java** (100 scripts en total, uno por ejercicio en cada lenguaje).

##  Objetivo del proyecto
Practicar fundamentos de programación como:
- Entrada y salida de datos
- Operaciones matemáticas básicas
- Cálculos de áreas y perímetro de figuras geométricas
- Conversión de unidades temperatura, longitud
- Uso de variables y tipos de datos

##  Tecnologías usadas
- Python
- Java
- IDE: IntelliJ IDEA / NetBeans

##  Estructura
- `/python` → ejercicios resueltos en Python
- `/java` → ejercicios resueltos en Java
